# NetSwitch · PC 网络控制开关

给测试工作用的一键网络开关，避免反复拔网线 / 关 WiFi。三种模式互不干扰。

---

## 首次使用（必须做一次）

`NetSwitch.exe` **必须右键 → 以管理员身份运行**一次，否则网卡开关和防火墙规则都会失败（程序左上角会标红提醒）。

首次以管理员运行后，点右下角 **「创建免UAC快捷方式」**，会在桌面生成
`NetSwitch 免UAC.lnk`——以后直接双击即可管理员运行，不再弹 UAC 提示。

> 原理：创建一个以最高权限运行的计划任务，快捷方式实际调用 `schtasks /run`。

---

## 功能

### 模式一 · 整机断网
- 选择网卡后点 **断开网络 / 恢复网络**，等价于禁用/启用网卡
- **断开全部网卡 / 恢复全部网卡**：默认会自动跳过 Hyper-V、WSL、Docker、VMware、TAP 等虚拟网卡，
  避免连带搞挂容器和虚拟机（可用复选框关闭该保护）
- 状态指示灯 + ping 检测（对阿里 DNS 223.5.5.5）实时显示是否真的通网
- **断网后自动恢复**：勾选后倒计时 N 秒强制恢复，防止测着测着把自己锁死在离线状态

### 模式二 · 循环断网（模拟弱网抖动）
按 `断 X 秒 → 连 Y 秒` 反复切换，可设轮数（0 = 不限）。
适合测客户端的断线重连、超时重试、状态机恢复逻辑。
随时点 **停止并恢复**，一定会把网络拉回来。

### 模式三 · 只掐单个应用的网络
- 选一个 exe（**浏览…** 或 **从进程选**，支持搜索），点 **阻断该程序**
- 原理是写 Windows 防火墙的出站 + 入站阻断规则，**只对这个 exe 生效**，其他软件正常上网
- 适合整机不下线、单独验证某个客户端的离线表现
- 阻断列表双击可反填路径，方便再点放行
- **清理全部阻断规则**：一键删掉本工具创建的所有防火墙规则

## 快捷键

| 热键 | 作用 |
|---|---|
| `Ctrl + Alt + K` | 断开网络 |
| `Ctrl + Alt + R` | 恢复网络 |
| `Ctrl + Alt + S` | 停止循环任务 |

> 全局热键依赖 `keyboard` 库，已打包进 exe。若失效会在底部提示。

---

## 已知注意事项

1. **防火墙规则只对新连接生效。** 已经是 ESTABLISHED 的长连接可能不断，建议阻断后重启被测程序再验证。
2. **断网后本机远程桌面会断开。** 如果在远程机器上跑，用模式三（单应用）更安全，或者务必勾上自动恢复。
3. 公司装了 iOA / VPN 类安全客户端时，禁用网卡可能触发其重连逻辑，属正常现象。
4. 配置文件 `netswitch_config.json` 会自动生成在 exe 同目录，保存上次选的网卡、程序路径和循环参数——删掉即重置。

## 文件

| 文件 | 说明 |
|---|---|
| `NetSwitch.exe` | 主程序（单文件，无需安装 Python） |
| `netswitch.py` | 源码 |
| `netswitch_config.json` | 运行后自动生成的配置 |

版本 v1.0.0 · Python 3.11 + tkinter，PyInstaller 打包

需要改源码重新打包时：

```bat
pyinstaller --noconfirm --onefile --windowed --clean --name NetSwitch ^
  --hidden-import=keyboard --hidden-import=win32com.client netswitch.py
```

打包必须在**带 tkinter 的 Python** 环境下进行。
