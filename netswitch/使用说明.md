# NetSwitch · 跨平台网络控制开关

给测试工作用的一键网络开关，避免反复拔网线 / 关 WiFi。四种模式互不干扰。
支持 **Windows** 与 **macOS** 双平台。

---

## 首次使用（必须做一次）

### Windows
`NetSwitch.exe` **必须右键 → 以管理员身份运行**一次，否则网卡开关、防火墙规则、弱网都会失败
（程序左上角会标红提醒）。首次以管理员运行后，点右下角 **「创建免UAC快捷方式」**，会在桌面生成
`NetSwitch 免UAC.lnk`——以后直接双击即管理员运行，不再弹 UAC。

### macOS
DMG 默认**未签名**，首次打开会被 Gatekeeper 拦下。两种办法：
- 在 Finder 里**右键 NetSwitch.app → 打开**（出现警告也点打开，以后即信任）；
- 或终端执行 `xattr -d com.apple.quarantine /Applications/NetSwitch.app`。

运行需要 **root**：直接在终端 `sudo open NetSwitch.app`，或在 App 内点右下角 **「以 root 重启」**
（会弹密码框）。不提权则开关网卡 / 弱网都会失败。

## 功能

### 模式一 · 整机断网
- 选择网卡/服务后点 **断开网络 / 恢复网络**，等价于禁用/启用网卡
- **断开全部网卡**（仅 Windows）：默认自动跳过 Hyper-V、WSL、Docker、VMware、TAP 等虚拟网卡，
  避免连带搞挂容器和虚拟机（可用复选框关闭该保护）
- 状态指示灯 + ping 检测实时显示是否真的通网
- **断网后自动恢复**：勾选后倒计时 N 秒强制恢复，防止测着测着锁死在离线状态

### 模式二 · 循环断网（模拟网络抖动）
按 `断 X 秒 → 连 Y 秒` 反复切换，可设轮数（0 = 不限）。
适合测客户端的断线重连、超时重试、状态机恢复逻辑。随时点 **停止并恢复**，一定拉回网络。

### 模式三 · 只掐单个应用的网络（仅 Windows）
- 选一个 exe（**浏览…** 或 **从进程选**，支持搜索），点 **阻断该程序**
- 原理是写 Windows 防火墙的出站 + 入站阻断规则，**只对这个 exe 生效**，其余软件正常上网
- macOS 系统限制（pf 防火墙无法按进程精准断流），此模式在 Mac 上不可用——请用模式四弱网或模式一整机断网

### 模式四 · 弱网模拟（系统级，所有流量受影响）
参数：
- **下行 / 上行带宽 (kbps)**：0 = 不限速；快速档 64K / 256K / 1M / 10M / 100M
- **延迟 (ms)**、**抖动 (ms)**、**丢包 (%)**、**乱序 (%)**
- 点 **开始弱网** 生效，**停止弱网** 即恢复

实现：
- **Windows**：基于 WinDivert（pydivert，自带驱动），系统级对所有包做限速/延迟/丢包/乱序
- **macOS**：基于 `pfctl` + `dnctl`（dummynet）——原生内置，无需额外工具

> ⚠️ macOS 的 dummynet **只支持带宽 / 延迟 / 丢包**，抖动与乱序在 Mac 上无效（界面已置灰）。
> 弱网对所有进出流量生效，开启后建议重启被测程序再观察。

## 快捷键（Windows）

| 热键 | 作用 |
|---|---|
| `Ctrl + Alt + K` | 断开网络 |
| `Ctrl + Alt + R` | 恢复网络 |
| `Ctrl + Alt + S` | 停止循环任务 |

## 已知注意事项

1. **防火墙规则（模式三）只对新连接生效。** 已建立的 ESTABLISHED 长连接可能不断，建议阻断后重启被测程序再验证。
2. **断网后本机远程桌面会断开。** 远程机上跑请用模式三（单应用）或务必勾上自动恢复。
3. 公司装了 iOA / VPN 类安全客户端时，禁用网卡可能触发其重连逻辑，属正常现象。
4. 弱网是**系统级**的，会同时影响你自己的浏览器/下载——测完一定点「停止弱网」。
5. 配置文件 `netswitch_config.json` 自动生成在同目录，保存上次选的网卡、程序路径、循环与弱网参数——删掉即重置。

## 构建

### Windows（带 tkinter 的 Python）
```bat
pyinstaller --noconfirm --onefile --windowed --clean --name NetSwitch ^
  --hidden-import=keyboard --hidden-import=win32com.client ^
  --hidden-import=pydivert netswitch.py
```
弱网需要 `pydivert`：`pip install pydivert`（会带上 WinDivert 驱动二进制）。

### macOS（在本机 Mac 上）
```bash
bash build_mac.sh      # PyInstaller 出 NetSwitch.app
bash create_dmg.sh     # hdiutil 出 NetSwitch.dmg
```
或用 GitHub Actions 自动出 DMG（见 `.github/workflows/build-mac.yml`，产物在 Release，未签名）。
